# jeu_devinette_python
Description : jeu devinette, le joueur est sensé choisir un nombre aléatoire, il doit deviner le nombre caché qui est choisi par l'ordinateur
Le joueur a un nombre limité des tentatives, à la fin du jeu, dès qu'il choisi le nombre exact caché, il a aussi un compte rendu de nombre des tentatives auxquelles il a fait face avant d'arriver au bon nombre. Dans les cas ou il atteint le nombre de tentatives, le jeu s'arrête et il perd.
Fonctionnalités : nombre aléatoire, indications plus grand/plus petit, compteur de tentatives, limite de tentatives.
Technologies : Python.
Exécution : comment lancer le programme depuis le terminal.
