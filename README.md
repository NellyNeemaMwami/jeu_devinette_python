# jeu_devinette_python
Mon premier projet python : jeu devinette, le joueur est sensé choisir un nombre aléatoire, il doit deviner le nombre caché qui est choisi par l'ordinateur
Le joueur a un nombre illimité des tentatives, à la fin du jeu, dès qu'il choisi le nombre exact caché, il a aussi un compte rendu de nombre des tentatives auxquelles il a fait face avant d'arriver au bon nombre
